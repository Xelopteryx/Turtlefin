Turtlefin 2.0.0 — Deep Dive Update

The biggest update Turtlefin has ever had so far.

What's new since 1.9.9 (tested on Windows, Linux on Raspberry Pi 5, Android and Android TV):

- Demo: discover Turtlefin without a server, with real free films from the Blender Foundation, and a reworked guided tour (mouse, keyboard, remote and touch); nothing is saved
- Day and night scenery for all three themes, following the time of day (or always day, or always night): Aero's lagoon, which darkens towards the depths and lets the item's backdrop show through, Turtlefin's drifting colours, Nerd's circuit board; an animated startup for each theme
- Animations: the banner opens into the item page and flies back, page transitions that follow the order of the top bar, item page buttons popping in one after another, "Who's watching?" from left to right, a home screen that builds up piece by piece after login
- Smoothness: Turtlefin measures what your device can do and lightens the scenery on its own to hold 60 frames per second ("Scenery detail" setting); the banner flight is much smoother on the Raspberry Pi
- Item pages: watched episodes of a series or season ("8 / 24" and the percentage), Details tab as chips (genres, studios, people, audio languages with their flag)
- Redesigned end screen: what you just finished and three suggestions, with the summary of the one you pick
- Libraries: A–Z index and scrollbar, filtering by typing the first letters of a title, cards dealt only once per session (the animation can be turned off); a menu on every card (right click, long press, held OK): watched / unwatched, Download, Request
- Select several cards in grids (long press, mouse drag, held OK on a remote), then Request or Download them all at once
- Search redesigned for TV: suggestions, filter chips, advanced search, result count; typing a letter on the home screen opens search
- Seerr: search by studio or network ("disney", "pixar"…), a person's filmography, request state shown on cards (pending, approved, available)
- Settings sorted into sub-categories, with a settings search and text size
- Administrators: edit an item from its page (information and images), Identify, Refresh, server dashboard
- Discord status: what you are watching on your Discord profile (off by default, Settings → Display → Sharing)
- Android: Android TV at the right scale, better support for phones held upright, an APK for 32-bit devices, symbols (★ ✓ ●) finally displayed, a single launcher icon
- Mods in a sandbox (no files, no programs, no network)
- The interface addresses you formally in every language
- Security: a mod can no longer reach outside the allowed media paths, demo server bounded, url library updated (RUSTSEC-2026-0592)
- Fixes: shortcut icons after a theme change, frozen picture when leaving the player, overlapping chips in the Details tab on phones, card menu under the Android navigation bar, keyboard selection restarting from the hovered poster, cut-off buttons on phones, and many more

Thanks to LainX84 for their suggestions (issue #2): the A–Z index, keyboard filtering, springy scrolling, dealing the cards once per session and the card menu all grew out of their ideas.
